# Hood Boss Team Lead Briefing

Single-file briefing theater from the Hood Boss Team Lead packet.

Open `index.html` in a browser, or host it on **GitHub Pages**. No build step.

`https://antmanthepro.github.io/hood-boss-team-lead-briefing/`

## What it does

- 14-chapter briefing (mission through compile)
- Drill capture with ownership scoring
- Readiness gates, STAR hard-story, Control Tower, workflow, evidence
- JSON + HTML record export
- Session saved in this browser only

Arrow keys / Space move chapters. **D** drill. **C** compile. **B** brief.
